## 🏧 ATM Simulator

A command-line script that simulates real-world automated teller machine interactions. This project served as my core practical exercise for mastering **nested conditional logic** and input validation.

### 🌟 Key Concepts Practiced
- **Nested `if/elif/else` Decisions:** Routing transactions securely based on correct credentials.
- **State Management:** Tracking and updating the account balance (`AB`) dynamically.
- **Input Cleaning:** Using `.strip()` to prevent whitespace errors during menu selections.
- **Data Type Casting:** Ensuring user inputs are handled as accurate integers (`int`).

### 🚀 How to Run It
1. Run the `atm_simulator.py` script in any Python environment.
2. Enter the default pin: `1234`
3. Follow the menu prompts to safely practice withdrawing or depositing funds.
